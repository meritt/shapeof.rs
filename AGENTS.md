# shapeof

Rust core behind a C ABI, shipped as a crate, a WebAssembly npm package and a Swift package. Design: [docs/architecture.md](docs/architecture.md).

## Layout

| Path | Contents |
|---|---|
| `crates/shapeof-core` | public Rust API; no `unsafe`, no I/O |
| `crates/shapeof-ffi` | C ABI; `include/shapeof.h` is generated by cbindgen |
| `xtask` | header, build, release set |
| `packages/npm`, `packages/swift` | bindings; the Swift manifest is `Package.swift` at the root |
| `testdata/cases.json` | conformance cases replayed by the Rust, npm and Swift tests |

## Toolchain

rustup (pinned by `rust-toolchain.toml`; not Homebrew `rust`), macOS 26 with Xcode 26, Node.js per `.nvmrc`, pnpm 12, `wasm-opt` from binaryen 133 (`WASM_OPT` overrides the path).

## Checks

```bash
cargo fmt --all --check
CARGO_BUILD_WARNINGS=deny cargo clippy --workspace --all-targets --locked
CARGO_BUILD_WARNINGS=deny cargo clippy -p shapeof-core -p shapeof-ffi --locked --target wasm32-unknown-unknown
RUSTDOCFLAGS="-D warnings" cargo doc --workspace --no-deps --locked
cargo xtask header --check
cargo deny --locked check
cargo test --workspace --locked
cargo package -p shapeof-core --locked
cargo +nightly-2026-11-01 miri test -p shapeof-ffi --locked
cargo xtask dist
```

CI runs the same set and `cargo semver-checks` against the last release: `.github/workflows/ci.yml`.

## Rules

- `include/shapeof.h`, `shapeof-ffi` and the wasm32 offsets in `packages/npm/shapeof.js` change together; `cargo xtask header` regenerates the header.
- The macOS floor changes together in `Package.swift` and `MACOS` in `xtask`.
- `testdata/cases.json` holds the expected reports, written from intended behaviour; a case changes only with the behaviour it pins. `SHAPEOF_CORPUS` overrides its path.
- A schema never rejects its own examples: a string format is emitted only when every value matches it.
- No comments in code beyond `SAFETY:` notes, `# Safety` sections and constraints the code cannot express; design goes to `docs/architecture.md`.
- Commit messages: one Russian line, present-tense verb.

## Release

1. Set `version` in `Cargo.toml` (`[workspace.package]`) and `packages/npm/package.json`; merge to `main`.
2. Take the release set CI built for that commit and pin it:

   ```bash
   gh run download <run-id> --repo meritt/shapeof.rs --name release-set --dir /tmp/shapeof-set
   ```

   ```bash
   cargo xtask pin /tmp/shapeof-set
   ```

3. Merge the pin to `main`, tag it and push the tag:

   ```bash
   git tag -a vX.Y.Z -m "vX.Y.Z"
   ```

   ```bash
   git push origin vX.Y.Z
   ```

4. Once the Release workflow is green, publish the released tarball and the tagged crate:

   ```bash
   gh release download vX.Y.Z --repo meritt/shapeof.rs --pattern shapeof-vX.Y.Z-npm.tgz --dir /tmp/shapeof-npm
   ```

   ```bash
   pnpm publish /tmp/shapeof-npm/shapeof-vX.Y.Z-npm.tgz --access public
   ```

   ```bash
   git checkout vX.Y.Z && cargo publish -p shapeof-core --locked
   ```

Repository settings: immutable releases enabled.

Recovery:

| Failed at | Action |
|---|---|
| Identity, Gates, Build | rerun; for a code fix delete the tag (`git push origin :refs/tags/vX.Y.Z`), fix on `main`, tag again |
| Draft, Readback, Publish | `gh release delete vX.Y.Z --repo meritt/shapeof.rs --yes`, rerun |
| Immutability | rerun the failed job |
| Published release is wrong | release the next patch version |
